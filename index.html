Evaluating Confidentiality of Third-Party Secure Folder AppsStockholm University DSV · 2026

Investigated whether third-party Android vault applications (AppLock, Private Photo Vault, Calculator Photo Vault) meaningfully protect stored user data against logical acquisition. Using a rooted Android emulator (Pixel 7 AVD, Android 14), performed file system acquisition via Android Debug Bridge (ADB) and analyzed how each app stores, hides, or encrypts vault contents. Across all three applications, vault files were recovered in plaintext without cracking the user password — AppLock relied on directory obfuscation outside the package-scoped path, while the other two stored files directly in accessible locations. The findings suggest that the security claims of these apps are not supported by their underlying storage implementations, contrasting sharply with OEM-based secure containers that leverage Trusted Execution Environments (TEE) and hardware-backed encryption.

Developed a proof-of-concept Android application that uses Bluetooth Low Energy (BLE) beacons as location markers to deliver personalized, aisle-specific product information and discount offers to shoppers in real time.
